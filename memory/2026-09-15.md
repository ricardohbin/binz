# 2026-09-15

## Session 1 — CI

He asked for the minimum: "just need a simple action that runs the tests and
this kind for now. no release or other things." GitHub Actions.

Wrote `.github/workflows/ci.yml`: one `test` job on `ubuntu-latest`, triggered
on push to `main` and on every PR, with `concurrency` cancel-in-progress so a
new push to a PR kills the older run. Steps: `actions/checkout@v4`,
`dtolnay/rust-toolchain@stable`, `Swatinem/rust-cache@v2`, then
`cargo build --all-targets --locked`, `cargo test --locked`, and a loop that
runs every `examples/*.binz`. All three are `--locked` because `Cargo.lock` is
committed and the project has zero dependencies, so a lockfile change in CI
would mean something is wrong.

The examples step is not redundant: `tests/lang.rs` writes its own temp
programs and never touches `examples/`, so nothing else checks the shipped
programs still compile. All five pass locally; 66 tests green.

### What I deliberately left out, and why

- **`cargo fmt --check`** — the tree is 141 diffs away from default rustfmt.
  The code is hand-formatted at ~100 columns and rustfmt's default is 100
  too, so this is real drift, not a config mismatch. Turning it on means one
  large reformat commit first. His call; not doing it under "minimum CI".
- **`cargo clippy -D warnings`** — exactly 3 lints: an unneeded `return`, a
  loop that wants `while let`, and `enum_variant_names`. The first two are
  one-liners, but the third wants a *rename* of a variant, which is a naming
  decision and therefore his, not mine. Left the whole job out rather than
  ship a red badge or half-fix it.
- No release, no cross-platform matrix, no coverage — he said so explicitly.

Tree left uncommitted, as always.
