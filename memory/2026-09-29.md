# 2026-09-29

## Session 1 — `binz lsp` (completion + diagnostics) and Zed wiring

His ask: "add LSP in binZ to autocomplete binz files".

### What landed (uncommitted, his to commit)

- `binz lsp` subcommand -> `src/lsp.rs`: JSON-RPC over stdio, hand-rolled.
  **No new dependency**: it reuses `src/json.rs` (`Json` is now `pub`, plus
  `json::document`, `Json::get/as_str/as_i64/to_text`). Full sync only.
  Negotiates `utf-32` positions if offered, else converts UTF-16.
- `src/complete.rs`: completion from **tokens, not the AST** (half-typed
  buffers don't parse). `Lexer::tokenize_lossy` drops the rest of a line that
  fails to lex and keeps going. Offers: stdlib members (`io.`), local module
  functions (`math.`, reads the file), struct fields via chains and `(*p).`
  (never `p.` on a pointer), `Error` fields, locals alive at the cursor
  (block scope + params), types after `:`/`cast<`/`Vector<`/`*`, tags per
  position (`@test`/`@json` top-level, `@field` in a struct body), and
  `binz/` / `@root/` paths in imports. Test functions and `main` are never
  offered. 15 unit tests.
- Diagnostics: `loader::load_with(entry, root, overlay)` + `compile_tests`
  (so modules with no `main` and tests are checked). Open buffers overlay the
  disk. Every open doc is re-checked on any change; an error in an imported
  file shows on the import line as `@root/x.binz:L:C: msg`. Compiler calls
  are behind `catch_unwind`.
- `@root` guess (`complete::root_for`): nearest dir upward where all the
  file's `@root/` imports exist; no local imports -> the file's own dir.
- Zed: `editors/zed/Cargo.toml` + `src/lib.rs` (zed_extension_api 0.7.0),
  `[language_servers.binz]` in `extension.toml`. Finds `binz` on PATH or
  `lsp.binz.binary.path` in settings. `target/` gitignored.
- `src/lexer.rs` diff is large only because `tokenize`'s loop body moved
  into `fn token` (reindent). Behaviour unchanged.

### Verified

- `cargo test`: 30 unit + 142 e2e green. Drove the real binary over stdio:
  all 13 example files open with zero diagnostics; an unsaved break in
  `modules/geometry.binz` shows in both importers on the import line.
- Zed extension crate passes `cargo check` on the host.
